# Changelog

## 0.1.0

- `sillo-agent` CLI: `install`, `update`, `uninstall`, `status`, `doctor`, `info`, `list`,
  `skills show|coverage|route`, and `dev` tooling for skill authors.
- Host adapters for Claude Code, OpenCode and Codex, with a manifest-based, idempotent installer.
- 39 skills against Sillo 1.x, including `sillo-oauth`, `sillo-wire`, `sillo-graphql`,
  `sillo-admin` (warder) and `sillo-scaffolding` (sillo-start).
- Capability inventory, API surface snapshots and behaviour probes backing skill validation.
